Spellbook paper backup

See your recovery words without your agent ever seeing them. This page makes a one-time reveal key; your agent gets only its public half and hands back an envelope that only this open tab can decrypt.

Do not reload or close this tab until the words are on paper. The reveal key lives only in this tab's memory and cannot be exported; reloading destroys it. No network requests are possible from this page.
1

Make a reveal key

Your agent runs sudo spellbook export --reveal-key <this public key>. That prints only an envelope, encrypted to this key, which your agent pastes back to you. This envelope carries no daemon key fingerprint: the one to trust is on your own terminal (spellbook export, or sudo spellbook ceremony-key), because your agent knows this public key and could write an envelope of its own.
2

Open the envelope

Write every word set shown and the addresses on paper, offline, in two copies kept in two places. Then clear the screen.

An install that keeps only your passwordless sealed seed shows the SET 1 addresses and no words: the words are the ones you typed on the restore page, and your paper copy must derive these addresses.

3

Confirm the backup

Until your daemon gets this one-time code back, the wallet refuses every fund-moving request (reads still work). Send the code only after the words are on paper.

Hand it back. Paste the code to your agent, who pipes it on stdin to sudo spellbook backup-confirm, or run that command yourself and type it at the prompt. The code only confirms your backup: it cannot open or move the wallet. One use, valid 7 days.
